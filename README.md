# 上海工资计算器 / Shanghai Salary Calculator

独立的中英双语静态工资测算工具，无第三方脚本或服务端，打开 `index.html` 即可使用。

## 计算范围

- 中国税收居民在同一单位从 1 月起连续 12 个月、工资和扣除固定的累计预扣估算。
- 外籍国籍不自动决定税收居民身份，也不自动豁免社保。
- 社保按参考基数估算，或填写核定基数；公积金填写实际个人月缴额。
- 默认社保参考工资 12,577 元、上下限 7,546 / 37,731 元适用于 2026 年 7 月起。本工具以同一组参数投影 12 个月，不能作为 2026 全年历史工资单。
- 年终奖按符合条件的全年一次性奖金单独计税，不自动比较并入综合所得方案。
- 专项附加扣除与外籍免税津补贴互斥；住房租金与贷款利息互斥。大病医疗只在年度汇算处理，本工具不计算。
- 不处理非居民、跨境所得、年中入职、工资变化、其他综合所得和年度汇算。
- 本工具结果为估算，具体申报及资格以适用政策与单位核定信息为准。

专项扣除调整自 2023 年 1 月 1 日起生效，参见[税务总局说明](https://www.chinatax.gov.cn/chinatax/n810356/n3255681/c5214546/content.html)。页面保持简洁，不展示政策核对区域。

## 本地使用和测试

直接打开 `index.html`，或运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765/`。

测试使用 Node.js 和 jsdom：

```sh
npm install --prefix .qa --no-audit --no-fund jsdom
node --test tests/payroll.test.cjs
```

默认不保存工资输入；用户可以主动开启浏览器本地保存，也可以一键清除。

## GitHub Pages

仓库建议名：`foreigner-payroll`。在 Settings → Pages 中选择 GitHub Actions，推送到 `main` 后自动部署。
工作流只发布 `index.html` 和 `.nojekyll`，不发布测试、工具箱仓库或开发文件。

工具箱主页仓库仅在 `src/data/tools.json` 添加指向独立 Pages 地址的卡片，不复制本工具源码。
